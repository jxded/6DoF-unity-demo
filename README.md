Try it out at (https://jxded.github.io/6DoF-unity-demo/)! Please ensure you have a monitor that is at least 1920x1080, preferably more. 
Please note that currently only a crude CCD algorithm to estimate IK is applied, so some locking and glitching may happen. Better algorithms and visual QOL and upgrades are TBD.

A crude implementation of FK (Forward Kinematics) and somewhat-deterministic IK (Inverse Kinematics) for coordinate resolution of a robot arm with 6 Degrees of Freedom. 

This was a quick 1/2 hour project, polishing and more features are to come.
